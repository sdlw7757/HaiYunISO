## 二、系统架构

```
┌─────────────┐   定时/手动    ┌──────────────────┐
│ crawler.js   │ ───────────▶ │  双站适配器        │
│ (编排/限速)  │               │ site_52ybcj.js    │──┐
└─────────────┘               │ site_msdngho.js   │  │ fetch+解析
                              └──────────────────┘  ▼
┌─────────────┐   白名单投影   ┌──────────────────┐
│ server.js    │ ◀─────────── │  SQLite haiyun.db │
│ (HTTP/API)   │   全字段(后台) │ systems/links/    │
└─────────────┘               │ sites/crawl_logs  │
      │ 静态页面               └──────────────────┘
      ▼
public/（首页/列表/详情/免责声明/后台管理）
```

- **零外部依赖**：Node ≥ 22.5 内置 `node:sqlite`；HTTP 服务用 `node:http`；抓取用内置 `fetch`。
- **并发安全**：WAL + `busy_timeout=5000`，服务器与采集器可同库并发。

## 三、采集器设计

### 3.1 通用能力（crawler/http.js + parse.js）
- 请求：桌面 Chrome UA、25s 超时、失败重试 1 次、同站 1.2s 间隔、GBK 自动兜底解码。
- 链接分类：百度盘/夸克/天翼/阿里/蓝奏/迅雷/OneDrive/123云盘/微云/移动云盘/MEGA/城通 → `netdisk`；`.iso/.esd/.gho/.wim` 与文件服务路径 → `direct`；`magnet:/ed2k:/thunder:` 协议链接。
- 提取码：URL 参数（`?pwd=`）与邻近文本（"提取码/访问码/密码：xxxx"）双通道。
- 字段识别：分类（Server 优先）/版本代号/Build（标题括号 + "内部版本"双规则）/架构/类型标签/变体/更新类型/特性标签 16 条规则/硬件适配语句/MD5-SHA1-SHA256/文件名/文件大小。

### 3.2 站点实测结论（2026-09 采样）
| 站点 | 结构 | 链接可得性 |
|---|---|---|
| 52ybcj | WP+Begin 主题，`/system/page/N`（实际 4 页，约 92 条目） | 原版类文章正文直出夸克/百度/天翼 + `ntriver.org` 直链 + SHA-256；不忘初心转载类 `read-secret` 登录墙 → 标记 `gated` |
| msdngho | 经典分类站 `/win10 /win11` + **品牌机系统 `/oem`（10 个品牌子页）** | **已启用采集**（最新指令：补全 OEM 分类）；详情页含高速直链/夸克/百度/天翼/迅雷链接，全量入库 |

### 3.3 状态机
`crawl_status`: `pending → ok（链接已归档）/ gated（源站受限，可人工补录）/ no_links / placeholder`
`gated` 条目保留全部版本档案信息；后台补录链接后自动升级为 `ok`。

## 四、数据库设计

见 README 第三节表格。要点重申：
- **前后端字段隔离是代码强制**：`db.toPublic()` 仅输出 `PUBLIC_FIELDS`；`/api/systems*` 不接触 `download_links` 表。
- **download_links** 仅 `/api/admin/*`（`X-Admin-Token`）可达。
- 手动补录链接带 `origin='manual'` 标记，自动采集不覆盖人工数据。

## 五、前端设计

- 视觉：深空底色 + 固定网格 + 双光晕 + Canvas 粒子连线（≥110 点、尊重 `prefers-reduced-motion`）、玻璃拟态卡片（blur + 悬浮辉光）、渐变发光标题。
- 首页：Banner + 站点级统计（档案数/活跃站数）+ 四分类入口（带实时计数）+ 最新收录 8 + 热门浏览 8 + 全站搜索。
- 列表页：四维筛选（版本/类型/特性/更新）+ 排序 + 关键词检索 + 状态同步 URL 参数 + 分页；卡片展示全部白名单徽标。
- 详情页：左栏下载链接面板（聚合网盘/直链/磁力/迅雷 + 提取码一键复制 + 来源站兜底）+ 简介/特性/硬件适配/特性标签，右栏参数表（含 MD5/SHA256 一键复制）+ 🛡️ 资源说明 + 一键免责声明按钮。
- 免责声明页：五节完整声明（站点性质/链接归档说明/版权/使用限制/生效更新），顶部黄色警示框复述定稿声明。
- 下载链接由详情页聚合展示（第三方来源公开链接 + 提取码 + 来源站兜底），不存储/不托管任何镜像文件，随档附免责声明。
- 更新：按最新指令，**每个系统在详情页展示对应的聚合下载链接**（第三方来源公开链接），并保留明确免责声明；OEM 分类由 msdngho 品牌机系统补全。

## 六、后台管理（/admin）

令牌登录 → 总览（站点状态卡 + 档案/链接/受限计数 + 采集日志表）→ 档案表（站点/状态/分类/关键词）→ 档案抽屉（全字段 + 链接清单 + 复制/删除 + 手动补录表单）+ 采集触发按钮。

## 八、风险与后续
